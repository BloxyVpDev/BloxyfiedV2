# Bloxyfied

A static website: login/create account, a marketplace with 3,780+ items (including 100+ expensive Mythic items), player profiles, a Bx shop with subscriptions, and a cosmetics store.
No build step. Plain HTML, CSS and JavaScript, ready for **GitHub + Cloudflare Pages**.

## Files

| File | What it is |
|------|-----------|
| `index.html` | Log in / Create Account page |
| `home.html` | Marketplace (categories, search, sort, buy), profile card, users online |
| `profile.html` | Your profile and other players' profiles |
| `shop.html` | Buy Bx, subscriptions, and the Bloxyfied Store (name colors, banners, titles, crates, boosters) |
| `app.js` | Shared logic: accounts, catalog, Bx, profiles, store |
| `style.css` | All styling |
| `_headers` | Security headers for Cloudflare |

## How it works

- Accounts (username + password) are saved in the visitor's **browser localStorage**, so they stay after closing the tab or refreshing.
- Passwords are **salted and hashed (SHA-256)**, never stored as plain text.
- An account exists **only on the device/browser where it was created**. It will not follow the user to another device, and clearing site data deletes it.
- New accounts get **500 free Bx**.
- Buying Bx and subscriptions is **instant and free** (no payment is taken). Anyone can top up their own balance.
- The 3,780+ marketplace items are generated by `app.js`, so they are the same for everyone.
- "Other people's profiles" are 30 sample players plus any accounts created in the same browser.

## v3 additions

- **Expensive items:** ~125 Mythic items (25,000 to 4,000,000 Bx) plus the Limited item **Dominus Of The Banned** (50,000,000 Bx, stock 3). Use the **💎 High Value** chip on Home.
- **Warnings:** Dominus has its own high-risk warning, and 13 more high-priced items show a fraud or scam warning. Buying one asks for confirmation first. They are defined in `FLAGGED` in `app.js`.
- **Stock:** every item has a stock number. Buying reduces it, and at 0 it shows Sold out. Stock is tracked per browser (localStorage). Add Product has a stock field.
- **Join dates:** sample players join between 16 Jan 2022 and Oct 2026. Some have fixed dates (`FIXED_JOIN`), the rest are random but stable. Change `JOIN_MIN` / `JOIN_MAX` to move the range.
- **Chat:** open any sample player's profile to chat. Replies are generated in the browser from keywords in your message plus that player's data (items, level, join date). No server or AI needed.

## v4: online players, messages and trades (needs a free Cloudflare D1 database)

Accounts, messages and trades between **different people on different devices** need a server. This version includes one: `functions/api/[[path]].js` (a Cloudflare Pages Function). It only works after you connect a database:

1. Cloudflare dashboard > **Storage & Databases** > **D1** > **Create database** (name it e.g. `bloxyfied-db`). No tables to create, the site makes them automatically.
2. Open your Pages project > **Settings** > **Bindings** (or **Functions**) > **Add** > **D1 database**. Variable name must be exactly **`DB`**, pick your database. Add it for **Production** (and Preview if you use it).
3. **Deployments** > redeploy (or push any commit). Deploy with **Connect to Git**; drag-and-drop uploads do not include Functions.

What you get once it is connected:

- **Real accounts across devices:** log in anywhere with the same username and password. Existing accounts made before this update are uploaded to the server the first time their owner logs in.
- **See each other:** real players appear in Players and Users Online, with an online dot, and their profiles show their real inventory.
- **Messages:** 💬 Message button on a profile, or Messages in the menu or sidebar. Unread count shows as a red badge.
- **Send Trade:** 🔁 Send Trade button on a profile. Pick items from both inventories. The window shows each item's **RAP** and a fairness check. The other player gets the offer under Trades and can Accept or Decline. Accepting swaps the items for both players.
- **RAP** (recent average price) is shown on every item card, item popup and trade window.

Without the database the site still works exactly like before (everything stays in your own browser), and the online buttons show a message instead.

Notes: the server keeps a copy of each account (Bx, XP, inventory, cosmetics, bio). Bx and purchases are still decided in the browser, as before, so this is a fun community site, not a secure economy. Passwords are hashed on the server (PBKDF2). Sample players (the 30 bots and Bloxyfied) cannot trade, only chat. Items put on sale with Add Product are still only visible in your own browser.

## Upload to GitHub

1. Create an empty repository on https://github.com/new (e.g. `bloxyfied`).
2. In this folder run:

```bash
git init
git add .
git commit -m "Bloxyfied v2"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/bloxyfied.git
git push -u origin main
```

(No git? On the GitHub repo page use **Add file > Upload files**, drag in every file, and commit.)

## Deploy on Cloudflare Pages

1. https://dash.cloudflare.com > **Workers & Pages** > **Create** > **Pages** > **Connect to Git**.
2. Pick the repo. Framework preset **None**, build command empty, output directory empty.
3. **Save and Deploy**. You get a link like `https://bloxyfied.pages.dev`.
4. Every `git push` redeploys automatically.
